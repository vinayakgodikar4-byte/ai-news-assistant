AI News Assistant
🧠 AI-powered News Analyzer with Summarization, Sentiment Analysis & Chatbot (Streamlit UI)

🌟 Features
✨ Abstractive Summarization
✨ Extractive Summarization
✨ Sentiment Analysis (Positive / Neutral / Negative)
✨ ROUGE Score Evaluation
✨ Interactive Chatbot (Ask anything about news)
✨ Clean & Modern Streamlit UI
🖥️ Demo Preview
 
⚙️ Tech Stack
- 🐍 Python
- 📊 Streamlit
- 🤖 NLP (NLTK / Transformers / Scikit-learn)
- 📈 ROUGE Evaluation
- 📦 Pandas / NumPy
📂 Project Structure
ai-news-assistant/
│── app.py                # Streamlit UI
│── news_assistant.py     # Core logic (NLP + Models)
│── requirements.txt      # Dependencies
│── .gitignore
│── README.md

🚀 Installation & Run
1️⃣ Clone the repository
git clone https://github.com/your-username/ai-news-assistant.git
cd ai-news-assistant

2️⃣ Install dependencies
pip install -r requirements.txt

3️⃣ Run the app
streamlit run app.py

💡 Usage
- Select a news article
- Click:
  - ✨ AI Summary
  - 📄 Extractive
  - 😊 Sentiment
  - 📊 ROUGE Score
- Use chatbot to ask:
  - summary
  - short
  - sentiment
  - explain
  - impact
